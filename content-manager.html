말씀 문답 콘텐츠 준비

앱 공지와 월별 문답 파일을 준비하는 페이지입니다. 여기서 저장한 파일을 기존 GitHub Pages 웹사이트에 올리면 앱에서 받아옵니다. 이 페이지는 서버의 계정·점수·신고 기록을 변경하지 않습니다.

1. 이미지 공지

기존 공지 파일이 있으면 먼저 불러오세요. 새로운 공지는 새로운 공지 ID를 사용해야 이미 닫았던 사용자에게도 표시됩니다.

이미지는 각각 2MB 이하 PNG/JPG/WebP를 사용하세요. 이미지는 선택한 원본 파일을 직접 업로드합니다. 이미지 안의 글도 각 언어로 준비해 주세요.

2. 월별 문답

번역까지 완성된 추가 문답 JSON을 불러오세요. 기존 catalog.json도 불러오면 지난 문답을 유지하면서 합칩니다. 정답 번호는 0부터 시작하며, 한·영·스페인어 선택지 순서가 같아야 합니다.

권별 카테고리 ID
바울서신: 로마서, 고린도서, 갈라디아서, 에베소서, 빌립보서, 골로새서, 데살로니가서, 디모데서, 디도서, 빌레몬서
공동서신: 히브리서, 베드로서, 야고보서, 요한서, 유다서
새 문답은 위 한글 ID를 그대로 사용하세요. 전·후서 문답도 같은 ID에 넣습니다. 기존 문제 ID는 바꾸지 마세요. NEW 날짜는 UTC 기준입니다.

새 문답 NEW 표시

기존 catalog.json과 비교해 실제로 새로 추가한 문제 수를 계산합니다. 본문만 수정한 문제는 NEW로 갱신하지 않습니다. 바울서신·공동서신의 NEW는 하위 권에도 함께 표시됩니다. 앱 코드12 이상에서 보입니다.

문답 ID는 매번 바꾸지 마세요. 같은 문답의 ID를 바꾸면 다른 문제로 인식되어 포인트·오답 기록 연결이 달라집니다.

결과와 업로드 위치

준비된 파일을 선택해 주세요.

공지: announcements/index.json과 같은 폴더에 이미지 업로드
문답: content/catalog.json 업로드
월별 콘텐츠를 올릴 때 개인정보처리방침·삭제 파일은 그대로 두세요. 관리자 도구 자체의 업데이트는 별도 시작 안내를 따르세요.

저장 버튼은 컴퓨터에 파일만 만듭니다. 실제 공개는 GitHub에 올린 뒤 이루어집니다. 코드11(2.3.2)부터 공지 목록은 앱을 새로 실행하거나 백그라운드에서 돌아올 때 비동기로 확인합니다. 연결 실패 시 이전 공지 캐시를 사용합니다. GitHub Pages 게시 반영 후 확인되며, 이미 닫은 공지를 다시 알리려면 새 공지 ID가 필요합니다. 이미지 교체 시 새 파일명/URL을 사용하세요. 월별 문답은 기존 최대 6시간 캐시를 유지합니다. 이전 앱 버전의 공지 확인 방식은 앱 업데이트 전까지 그대로입니다.
